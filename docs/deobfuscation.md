# Деобфускация кода

1. **Расшифрованная строка:**
`import os; os.system('rm -rf /')`

2. **Анализ угрозы:**
Команда выполняет рекурсивное и принудительное удаление всех файлов в корневой директории операционной системы Linux. Это приводит к полной потере данных и выходу системы из строя.

3. **Методы защиты:**
* Запрет использования опасных функций выполнения кода вроде `exec()` и `eval()`.
* Внедрение инструментов статического анализа кода (например, Bandit).
* Запуск приложений с минимально необходимыми правами (не от суперпользователя root).
